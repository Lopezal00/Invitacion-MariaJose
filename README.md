# Invitación XV Años · María José Restrepo

Invitación digital de una sola página (HTML/CSS/JS puro, sin dependencias de build).

## Ver en local

Abre `index.html` directamente en el navegador, o sirve la carpeta con cualquier servidor estático.

## Despliegue

Este proyecto se despliega en [Vercel](https://vercel.com) como sitio estático. Al conectarlo con este repositorio, cualquier `git push` a `main` actualiza automáticamente el sitio publicado.
